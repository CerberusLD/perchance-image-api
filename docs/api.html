Referência da API

Backend Flask + Camoufox. O GitHub Pages serve esta página; a API roda no servidor configurado abaixo.
Configure a URL do backend.

Endpoints

MétodoRotaDescrição
GET/healthStatus do serviço e se o navegador Camoufox está pronto
GET/stylesLista dos 76 estilos
GET/generate?prompt=...Retorna a imagem JPEG diretamente
POST/generateJSON; use response_format=json para receber base64

Parâmetros

CampoTipoDefaultDescrição
promptstringobrigatórioDescrição da imagem
negative_promptstring""O que evitar
resolutionstring768x768512x512 | 512x768 | 768x512 | 768x768
guidance_scalefloat7.01–30
seedint-1-1 = aleatório
stylestring—Um dos 76 estilos
response_formatstring—json para base64

Exemplos

curl "https://SEU-BACKEND/generate?prompt=a%20cute%20cat&style=Cinematic&resolution=768x768" -o cat.jpg

curl -X POST https://SEU-BACKEND/generate \
  -H "Content-Type: application/json" \
  -d '{"prompt":"cyberpunk city","style":"Pixel Art","resolution":"768x512","seed":42,"response_format":"json"}'

Limitação do GitHub Pages

O Pages é estático: não executa Python, não abre navegador e não contorna Cloudflare/Turnstile. Além disso, a Perchance envia X-Frame-Options: sameorigin (bloqueia iframes de outros domínios) e o endpoint do ad code não tem CORS. Portanto a geração precisa do server.py publicado em algum host (local, VPS, Render, Railway, Fly.io). O repositório inclui Dockerfile, render.yaml e Procfile para facilitar.
