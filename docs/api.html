Referência da API

Backend Flask + curl_cffi (HTTP puro, sem navegador), hospedado no Render. Troque SEU-SERVICO.onrender.com pela URL do seu serviço.

Base URL

https://SEU-SERVICO.onrender.com

Endpoints

MétodoRotaDescrição
GET/Informações do serviço e lista de endpoints
GET/health{"status":"ok","ready":bool}
GET/warmupCria a sessão HTTP e valida o acesso (chame 1× após o deploy)
GET/stylesLista dos 76 estilos
GET/generate?prompt=...Retorna a imagem JPEG
POST/generateJSON (response_format=json) ou JPEG

Parâmetros de /generate

CampoTipoDefaultDescrição
promptstringobrigatórioDescrição da imagem
negative_promptstring""O que evitar
resolutionstring768x768512x512 | 512x768 | 768x512 | 768x768
guidance_scalefloat7.01–30, aderência ao prompt
seedint-1-1 = aleatório
stylestring—Um dos 76 estilos
response_formatstring—json para receber base64

Exemplos

# imagem direta (JPEG)
curl "https://SEU-SERVICO.onrender.com/generate?prompt=a%20cute%20cat&style=Cinematic&resolution=768x768" -o cat.jpg

# JSON com base64
curl -X POST https://SEU-SERVICO.onrender.com/generate \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "cyberpunk city at night",
    "style": "Pixel Art",
    "resolution": "768x512",
    "seed": 42,
    "negative_prompt": "blurry, low quality",
    "response_format": "json"
  }'

# saúde / aquecimento
curl https://SEU-SERVICO.onrender.com/health
curl https://SEU-SERVICO.onrender.com/warmup

{
  "ok": true,
  "image_b64": "/9j/4AAQSkZJRg...",

SDK JavaScript

<script src="perchance-api.js"></script>
<script>
  PerchanceAPI.setBase("https://SEU-SERVICO.onrender.com");

  const r = await PerchanceAPI.generate("a cute cat", {
    style: "Studio Ghibli",
    resolution: "768x768",
    guidanceScale: 7,
    seed: 12345,
    negativePrompt: "blurry, low quality"
  });

  document.querySelector("img").src = r.dataUrl;

  // lote
  const many = await PerchanceAPI.generateBatch("cyberpunk city", { resolution: "768x512" }, 2);
</script>

Códigos de erro

Observações

  • A primeira chamada após o deploy (ou após o serviço dormir) pode levar alguns segundos a mais; depois, ~5–15 s por imagem.
  • As chamadas são serializadas: uma geração por vez.
  • Sem navegador, o plano gratuito do Render (512 MB) é suficiente; a geração leva ~5–15 s.
  • Se o Render retornar token_required (IP de datacenter), configure PERCHANCE_PROXY com um proxy HTTP residencial/sticky.
  • GitHub Pages serve apenas esta documentação; a API roda no Render.
