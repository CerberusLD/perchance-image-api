Gere imagens com Perchance
através de uma API simples

Uma API REST open-source que envolve o gerador de imagens do Perchance com Flask + curl_cffi (HTTP puro, sem navegador). 76 estilos, resoluções, seed, negative prompt e controle de guidance — sem chave, sem cadastro.

Como funciona

Três camadas, cada uma no seu lugar.

1

Esta página (GitHub Pages)

Site estático de introdução e documentação. Não executa backend nem contorna Cloudflare.

2

API (Render + Docker)

Flask obtém o ad code e o userKey por HTTP (curl_cffi, TLS de Chrome) e chama a API interna do Perchance. Sem navegador.

3

Perchance

O navegador verificado chama a API interna do Perchance e devolve o JPEG para o seu app.

Comece em segundos

Depois de publicar a API no Render, troque SEU-SERVICO pela sua URL.

# imagem direta (JPEG)
curl "https://SEU-SERVICO.onrender.com/generate?prompt=a%20cute%20cat&style=Cinematic&resolution=768x768" -o cat.jpg

# JSON com base64
curl -X POST https://SEU-SERVICO.onrender.com/generate \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "cyberpunk city at night",
    "style": "Pixel Art",
    "resolution": "768x512",
    "seed": 42,
    "response_format": "json"
  }'
Geração em ~5–15 s. Sem navegador e sem aquecimento longo.
<script src="perchance-api.js"></script>
<script>
  PerchanceAPI.setBase("https://SEU-SERVICO.onrender.com");

  const r = await PerchanceAPI.generate("a cute cat", {
    style: "Studio Ghibli",
    resolution: "768x768",
    guidanceScale: 7,
    seed: 12345,
    negativePrompt: "blurry, low quality"
  });

  document.querySelector("img").src = r.dataUrl;
</script>
O SDK chama o backend e devolve dataUrl + metadados.

Deploy no Render

O servidor é um container Docker; o Render builda e hospeda.

  1. Fork ou use este repositório no Render.
  2. New → Blueprint e selecione o repositório (o render.yaml já está pronto).
  3. Aguarde o build do Docker (rápido: sem download de navegador).
  4. Abra https://SEU-SERVICO.onrender.com/warmup uma vez.
  5. Teste /health → {"status":"ok","ready":true}.
Sem navegador, o consumo é baixo: o plano gratuito do Render (512 MB) é suficiente. O free “dorme” após inatividade — a primeira chamada depois disso só demora alguns segundos para acordar.
