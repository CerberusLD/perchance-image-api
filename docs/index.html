Gere imagens com Perchance
através de uma API simples

Uma API REST open-source que envolve o gerador de imagens do Perchance com Flask + curl_cffi (HTTP puro, sem navegador). 76 estilos, resoluções, seed, negative prompt e controle de guidance — sem chave, sem cadastro.

Testar a API

Esta página chama a API publicada em perchance-image-api-vn4j.onrender.com. Você também pode apontar para outro servidor no campo abaixo.

Como funciona

Três camadas, cada uma no seu lugar.

1

Esta página (GitHub Pages)

Site estático + playground. Chama a API por HTTPS, sem backend próprio.

2

API (Render + Docker)

Flask obtém o ad code e o userKey por HTTP (curl_cffi, TLS de Chrome) e chama a API interna do Perchance. Sem navegador.

3

Perchance

O servidor gera a imagem e devolve o JPEG em base64 para esta página.

Use no seu código

A mesma API que o playground usa.

# imagem direta (JPEG)
curl "https://perchance-image-api-vn4j.onrender.com/generate?prompt=a%20cute%20cat&style=Cinematic&resolution=768x768" -o cat.jpg

# JSON com base64
curl -X POST https://perchance-image-api-vn4j.onrender.com/generate \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "cyberpunk city at night",
    "style": "Pixel Art",
    "resolution": "768x512",
    "seed": 42,
    "response_format": "json"
  }'
Geração em ~5–15 s quando o backend tem IP aceito. Sem navegador.
<script src="config.js"></script>
<script src="perchance-api.js"></script>
<script>
  const r = await PerchanceAPI.generate("a cute cat", {
    style: "Studio Ghibli",
    resolution: "768x768",
    guidanceScale: 7,
    seed: 12345,
    negativePrompt: "blurry, low quality"
  });
  document.querySelector("img").src = r.dataUrl;
</script>
O SDK chama o backend e devolve dataUrl + metadados.

Deploy

O frontend está no GitHub Pages; a API no Render.

  1. API: Render → New → Blueprint → este repositório (o render.yaml está pronto).
  2. Warmup: abra /warmup uma vez após o deploy.
  3. Frontend: o Pages publica a pasta docs/ a cada push em main.
Se o Render recusar a verificação do Perchance (token_required, IP de datacenter), a API usa o Pollinations automaticamente (grátis, sem chave) e continua devolvendo imagens. Para forçar o Perchance, configure PERCHANCE_PROXY com um proxy residencial/sticky. Continua sem navegador.
