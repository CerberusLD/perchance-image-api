Perchance Image API

Painel estático (GitHub Pages) + API Flask/Camoufox
frontend 100% estático GitHub Pages backend Flask Camoufox anti-bot Pages não executa servidor
Importante: o GitHub Pages é hospedagem estática — ele não roda Python, não abre navegador e não pode contornar o Cloudflare/Turnstile. A Perchance também bloqueia iframes de outros domínios (X-Frame-Options: sameorigin) e o endpoint do ad code não tem CORS. Por isso a geração real roda no server.py (Flask + Camoufox). Configure abaixo a URL pública desse servidor (local, VPS, Render, Railway, Fly.io) e esta página vira o painel completo da API.

🔌 API HTTP do backend

# imagem direta
curl "https://SEU-BACKEND/generate?prompt=a%20cute%20cat&style=Cinematic&resolution=768x768" -o cat.jpg

# JSON com base64
curl -X POST https://SEU-BACKEND/generate \
  -H "Content-Type: application/json" \
  -d '{"prompt":"cyberpunk city","style":"Pixel Art","resolution":"768x512","seed":42,"response_format":"json"}'

# saúde e estilos
curl https://SEU-BACKEND/health
curl https://SEU-BACKEND/styles
<script src="https://SEU-USUARIO.github.io/perchance-image-api/perchance-api.js"></script>
<script>
  PerchanceAPI.setBase("https://SEU-BACKEND");

  const r = await PerchanceAPI.generate("a cute cat", {
    style: "Cinematic",
    resolution: "768x768",
    guidanceScale: 7,
    seed: 12345,
    negativePrompt: "blurry, low quality"
  });

  img.src = r.dataUrl;          // base64 pronto para exibir
  console.log(r.seed, r.width, r.height);

  // lote
  const many = await PerchanceAPI.generateBatch("cyberpunk city", {resolution:"768x512"}, 2);
</script>
GET  /health                  -> { status, ready }
GET  /styles                  -> ["Cinematic", "Anime", ...]
GET  /generate?prompt=...     -> image/jpeg
POST /generate                -> JSON (response_format=json)

POST body:
{
  "prompt": "a cute cat",              // obrigatório
  "negative_prompt": "blurry",         // opcional
  "resolution": "768x768",             // 512x512 | 512x768 | 768x512 | 768x768
  "guidance_scale": 7.0,               // 1–30
  "seed": 12345,                       // -1 = aleatório
  "style": "Cinematic",                // opcional (76 estilos)
  "response_format": "json"            // json => { ok, image_b64, seed, width, height, ... }
}
# Local
.venv/bin/python server.py            # http://127.0.0.1:8000

# VPS / Render / Railway / Fly (Docker incluso no repo)
docker build -t perchance-api .
docker run -p 8000:8000 perchance-api
